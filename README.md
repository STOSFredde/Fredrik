# Warcraft-like Real-Time Strategy for Atari STE ⚔️🏰

An ambitious strategy game prototype built for the retro **Atari STE** hardware, programmed using **STOS BASIC**. 

This project explores the limits of STOS, pushing the 16-bit Atari hardware to handle unit movement, map rendering, and classic real-time strategy (RTS) mechanics.

## Features ✨
* **STOS BASIC Engine:** Built using modular STOS code and optimized with custom command extensions.
* **Atari STE Enhanced Palette and sound:** Utilizing the STE's hardware features for smooth performance.
* **Classic RTS Mechanics:** Inspired by early 90s strategy games like Warcraft.
* **Line-Numbered Architecture:** Codebase structured into clean, isolated modules (Input, Graphics, Game Logic) for easy maintenance.

## Project Structure 📁
* `/source`: Contains the STOS BASIC text source files (`.ASC`).
* `/build`: Contains compiled executable binaries (`.PRG`) and ready-to-run disk images (`.ST`).
* `/assets`: Sprite banks (`.MBK`) and map data.

## How to Play / Run the Demo 🕹️
To try out the latest demo, you can run the files using an Atari ST emulator (like **Hatari** or **Steem**), or transfer them to a real Atari STE.

1. Download the latest `.ST` disk image from the `/build` folder.
2. Load the disk image into your emulator of choice.
3. Set the emulator machine type to **Atari STE** with at least 1MB of RAM.
4. Run the main executable from the desktop or let it auto-boot.
